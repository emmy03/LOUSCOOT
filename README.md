# Projet de Location de Scooter - LOUSCOOT

Ce projet consiste en la gestion du parc de scooters d'un magasin de location, **LOUSCOOT**. Le logiciel permet de gérer la location, la réception et l'état des scooters. Il propose un menu interactif permettant aux utilisateurs de louer ou retourner des scooters, de connaître leur état et d'afficher des résumés sur le parc de scooters.

## Introduction

Le programme permet de simuler un système de gestion de location de scooters. Les utilisateurs peuvent choisir différentes actions via un menu, comme louer un scooter, retourner un scooter, ou connaître l'état de tous les scooters présents dans le parc.

## Technologies utilisées

- **Langage** : Java (Programmation orientée objet)
- **Outils** : IDE Java (Eclipse)
- **Architecture** : Utilisation de la programmation orientée objet (POO) pour organiser les différentes entités du programme (Scooter, Parc de Scooters, etc.).
